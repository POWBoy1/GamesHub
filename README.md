# GamesHub

Play games during school without raising suspicion!  
This project disguises the browser tab as **Google Classroom**, including both the **tab name** and **icon**, so even if a teacher uses a tab checker, it blends right in.

## Features
- Google Classroom style **tab name** and **icon**
- Fully **customizable** tab **names** and **icon**
- Browse **Games**, **Apps**, **Tools**, and manage **Favorites**
- Fully responsive **grid layout**
- **Fullscreen player** support for games and apps
- **Search functionality** across all categories and favorites
- Automatic **API version fetching**
- **Panic Key** to redirect you to Google Classroom (customizable)
- Easy to use — just open and play
- Updated frequently

## Notes
- Some games or apps might not work; if they are blocked, broken, or buggy, the provider may be updated
- Certain updates have been assisted by AI
- Favorites are stored locally in your browser
